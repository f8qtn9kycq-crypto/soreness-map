# 附圖盤髮與後頸接合修正

使用者在PR #3合併後、正式部署前要求改用附圖盤髮，並移除後頸髮尾凹口造成的斷開感。此要求取代先前H1短鮑伯選定；正式發布繼續等待新版介面確認。

僅修改可重現產生器與靜態SVG裝飾，92個位置路徑、74個紀錄身分、放大框逐欄位比對完全相同。未複製附圖像素或更動浮水印，保留原MIT圖形來源聲明。新增盤髮與髮流為原創SVG。

本機phase1 11項契約與female-map 7組驗證通過。IAB實際檢視正背面：背面原凹口取消，髮際線覆蓋原來源上緣多餘折線。真人視覺確認Pending；真機、VoiceOver與臨床位置未驗證。

前版Claude審查不涵蓋本輪。Claude桌面剛顯示額度用盡，獨立新head審查Pending，不將舊結果當新Pass。CI、Preview與後續審查以本PR留言紀錄為準。

後續使用者要求髮尾下緣沿附圖弧線並露出頭部下緣：已重畫背面髮際弧線，將來源軀幹上緣封口替換為連續後腦輪廓；頸部以下與全部互動路徑不變。IAB正背面再次實際檢視；新版仍待使用者確認。
