## 驗收行為

首頁第一屏可直接畫出範圍，點程度即更新草稿並收起評分面板，繼續下一處；最後只需儲存一次。無需先選分類／部位，也不要求逐筆完成。筆畫範圍與分數分開；每筆獨立，沒有平均或加總。重選不刪除，新增重疊筆畫用「新增一筆」。

放大只改相機視窗，不改筆畫座標；保留完整正背面人體。右／左腿內側與外側是分開的腿部體表示意，不自動跨面或跨腿投影。正背面與新側面固定為 surface-v1，未來換圖須新增版本保留舊圖。所有輪廓不是經治療師／教練驗證的解剖邊界。

新版歷史與草稿使用新 namespace；不回寫既有 bodymap.v1 或 bodymap.draft。legacy.html 保留原記錄與草稿流程。完整備份 v2 可含新舊歷史與草稿，匯入單次原子寫入新版主儲存區；舊 key 不變。非空草稿被取代前確認，取消則整批不變。完整 v2 不能用舊版還原，另提供舊紀錄 v1。CSV 是閱讀格式，預設排除自由文字；未指定趨勢部位不猜成肌肉。
