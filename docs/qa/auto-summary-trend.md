# 自動位置、即時人體總結與一眼可讀趨勢

日期：2026-10-28。Repo soreness-map；Tier 3（選用位置欄位與自動分類、趨勢）。沿用記錄／趨勢／總結三分頁，不加使用者拒絕的提示句。

## 行為與資料界線

新筆畫按固定版本體表範圍，自動顯示右小腿外側、右大腿內側等名稱。等弧長取樣含筆寬周邊，跨區保留多區、跨側不任選一側，無足夠命中則保留原圖面描述。不是診斷，也不把體表自動指定為某塊肌肉。舊筆畫不回填；手動部位索引保持原樣。

新 location 欄位通過封閉白名單驗證，可保存、備份與CSV往返；舊格式不補欄位，舊資料不重寫。自動位置趨勢按該位置集合／側別／表面分組，不硬套股四頭肌等舊分類；同組區域順序不同視為相同。

總結在儲存前即以原圖、原筆畫路徑、筆寬與顏色呈現，所有已畫視角並列；標記可滑鼠／Enter／Space返回編輯同一筆。保存後仍可看原有圖形歷史。

趨勢打開直接顯示各位置的最近日期／分數、與上一個有紀錄日期的差異、實際觀察散點；原部位查詢收於次要選項。多筆同日不同分數顯示範圍、不取平均、不推定升降；缺日不補0、不畫連續量測。單日資料明示再記一次才能比較。「三秒看懂」是設計驗收目標，沒有真人計時證據，不宣稱達成。
