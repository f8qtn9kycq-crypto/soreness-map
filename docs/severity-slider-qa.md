# 不舒服程度滑桿

風險 Tier 1：評分操作介面，量表維持1–10整數；不改人體圖、資料schema、歷史、趨勢、匯入匯出或醫療規則。

改為原生 range＋大數字／文字程度＋每次一分的減／加按鈕，色階沿用既有col。未評分顯示「尚未評分」，range呈現起點1但不寫草稿；按＋、拖曳、點按起點、方向鍵或Home/End才評分。0仍只代表清除此部位，不改為沒有不適。

input期間就地更新分數、aria-valuetext、色階、按鈕邊界與類型／備註可用狀態，不重建range或textarea。邊界按鈕保持焦點，以aria-disabled標示且動作限界。關閉／清除仍走既有流程；Tab循環包含range。
