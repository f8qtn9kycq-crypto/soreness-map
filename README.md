# 痠痛記錄 Soreness Map

無需帳號、無後端的單頁靜態記錄工具，支援臺灣繁體中文／英文、身體部位標記、不舒服程度、類型、備註、歷史與趨勢，以及 JSON 備份／匯入和 CSV 匯出。僅供自我記錄，非診斷或治療建議。

## 使用

以瀏覽器開啟網站，選「肌肉與軟組織」或「關節與區域」，再點選部位、程度及類型。儲存後可在「總結」查看，或在「趨勢」匯出 JSON／CSV。JSON 可用來還原與合併歷史紀錄；相同 id 的既有紀錄會保留。匯入支援原版備份與舊部位名稱，格式不符時整批拒絕，不部分寫入；檔案上限為 10 MiB。

資料存在同一瀏覽器、同一網站來源的 localStorage，沿用 `bodymap.v1`、`bodymap.draft`、`bodymap.lang`。換網址、瀏覽器或裝置不會自動帶入資料；部署網址和先前本機 HTML 也不共用資料。請先匯出 JSON，再於新網站匯入。CSV 是閱讀用途，非還原格式。

## 趨勢與位置的解讀

1–10 的分數、類型及既有色階沿用原本意義。「清除此部位」只移除目前草稿的該部位，不會儲存真正的 0 分或改動歷史紀錄。趨勢只顯示選定部位已記錄的有效正分，各次紀錄以獨立圓點呈現；未記錄日期、缺少部位及舊紀錄的 0 都不補成 0，也不能解讀為沒有不適或已康復。7／30／90 天依瀏覽器本地日期計算，包含今天。

部位名稱協助描述感覺位置，不能判定受傷組織或病因。中央或更細的位置可先填在備註；目前仍使用原有左右、前後及部位範圍，未新增位置維度。分享用 CSV 預設不含備註與訓練文字。

## 分享用 CSV 與完整備份

「趨勢」中的分享用 CSV 僅取已儲存歷史，不含目前草稿。起迄日期預設留空，代表全部日期；有填的日期包含當天。下載前會顯示可匯出的紀錄數及部位列數；無效日期、起迄倒置或沒有有效部位資料時不下載。

每列是一筆紀錄的一個已記錄部位，欄位為 `schema_version`、`entry_id`、`part_id`、`side`、`part_name`、`severity`、`types`、`date`。名稱與類型依當前介面語言顯示；穩定的紀錄 ID、部位 ID 與左右代碼可供辨識。只有主動勾選「包含訓練文字與備註」才加入 `workout`、`note` 欄位；兩者都可能含敏感資訊。勾選狀態只在目前頁面有效，重新開啟後回到不含文字。

分享 CSV 與完整 CSV 都只下載到本機，不會自動上傳 Google 或傳給他人，也不能用來還原。請保留「完整備份」中的 JSON：它仍包含全部歷史與自由文字，原有 JSON 匯入及完整 CSV 格式不變。既有舊 0 分仍保留在 JSON 備份，不做歷史遷移。

若要在 Google 試算表閱讀分享 CSV：

1. 先確認日期範圍、筆數與是否包含自由文字，再下載分享 CSV。
2. 自行開啟 Google 試算表，選擇「檔案 → 匯入 → 上傳」，選取下載的 CSV，確認分隔符號與匯入結果。
3. 上傳及後續分享由你決定；操作前請確認檔案內容、Google 帳號及共用對象。詳見 [Google 官方匯入說明](https://support.google.com/docs/answer/40608?hl=zh-Hant)。

## 本機執行與部署

直接開啟 `index.html`，或在本目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。不需安裝套件或建置。Vercel 部署時匯入此 GitHub repository，Framework Preset 選 `Other`、Root Directory 使用根目錄，不需 Install／Build Command。網站由根目錄的 `index.html` 提供，不需後端或環境變數。GitHub Pages 亦可使用根目錄，`.nojekyll` 已包含。正式網址以 repo 的 About／Website 欄位為準。

匯出使用標準 Blob、object URL 與下載連結，不依賴 Claude。CSV 欄位會加上引號並處理以公式符號或控制字元開頭的內容；若經其他工具重新編輯／另存，請重新確認其安全性。匯入日期、紀錄 id、部位、程度與欄位型別皆先驗證，文字備註以純文字顯示。

若瀏覽器內既有紀錄或草稿格式異常，頁面會顯示通知並保留該原始 localStorage 值，禁止自動覆寫異常欄位。本次頁面中的新資料可能無法持久保存；請先透過瀏覽器工具備份原始網站資料，並匯出目前頁面的新紀錄，確認備份後再清除網站資料重新開始。歷史匯出僅包含驗證後的目前歷史紀錄，不包含被拒絕的原始異常資料。

歷史儲存失敗時會保留目前草稿，不顯示儲存成功；警示中的「匯出目前草稿 JSON」可將草稿另存為可匯入的備份。匯入內容若未能寫入瀏覽器，仍保留於目前頁面供匯出，並明確顯示尚未儲存，可重新匯入重試。儲存空間或權限造成的失敗會另行提示；請先備份再重新整理。若歷史已成功儲存但舊草稿未能清除，會提醒重新開啟頁面可能再看到舊草稿。

瀏覽器可能限制檔案下載或儲存；無痕模式、清除網站資料及瀏覽器設定也可能影響保存。請確認備份實際下載成功。本工具沒有雲端同步。

## 本機契約驗證

執行 `node tests/phase1.test.cjs`，不需額外套件。測試涵蓋缺值趨勢、本地日期邊界、清除與歷史保真、穩定 ID、分享預設排除自由文字、日期篩選、CSV escaping／公式防護、完整備份與儲存失敗。這是本機程式契約驗證，不代表瀏覽器實際下載、Google 匯入、真機操作或醫療專業審核已通過。

## 女性人體圖（F2 體表輪廓＋盤髮）

使用女性體表輪廓與參考圖風格的盤髮（取代原H1短鮑伯選定）；依最新審閱移除內部肌肉解剖線，保留點選／已記錄位置的高亮，保留原37類／74左右key、正背面可見性與儲存格式，不新增前後或中央維度，不改寫歷史。同一key若原本出現在正背面，切面仍是同一筆觀察。左右以使用者本人為準：正面右在畫面左，背面右在畫面右。

點圖遇到多個相疊位置時會列出候選；也可直接用「或用清單選擇位置」。圖形未載入時，清單及紀錄／備份功能仍可使用。Enter／Space可開啟圖形位置，Esc關閉編輯面板。小部位、深層肌群附近或中央位置請配合文字與備註，不以圖像判定組織或病因。

[逐項位置對照](docs/female-map-locations.md)、[來源與MIT授權](THIRD-PARTY-NOTICES.md)。`assets/female-map.js` 須與 `index.html` 一起部署；產品仍無套件依賴或建置步驟。`python3 scripts/build-female-map.py` 可從repo內固定來源重建圖形，不需網路。

另執行 `node tests/female-map.test.cjs` 驗證身分／可見性／左右／放大框／清單替代與歷史保真。兩組契約由GitHub Actions於PR及main更新時執行。`tests/geometry-fixture.html` 提供原生SVG命中與多尺寸版面驗證；瀏覽器驗證不等同真機或臨床定位審核。

## 精細定位試用原型

[開啟細分位置原型](prototypes/detailed-locations.html)：涵蓋 37 類與左右部位，完整人體聚焦、圖文相對位置同步、個別評分與完成狀態。再次點選可編輯；切換定位精度、移除與清空可復原。手足其他表面以參考圖選取。

這是獨立試用頁，重新整理即清空；不讀寫正式紀錄、草稿、歷史或備份。分區描述主觀體表位置，不是經專家驗證的肌肉邊界。正式記錄仍使用首頁。見 [位置詞彙與公開參考](docs/detailed-location-catalog.md)、[驗證範圍](docs/qa/detailed-location-delivery.md)。
